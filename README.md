# ML From First Principles

Exploring classical statistics, forecasting, and machine learning through systems programming in Odin.

## Why This Project?

I work professionally with machine learning and forecasting, primarily using Python and established libraries.

This project is an opportunity to explore the mathematics and computational foundations of these algorithms by implementing them from first principles.

I'm especially interested in numerical computing, memory layout, performance, and understanding how statistical algorithms are represented and executed by computers.

## Goals

- Learn Odin and systems-level numerical programming.
- Implement classical statistical and ML algorithms.
- Investigate numerical stability and computational performance.
- Validate results against established reference implementations.
- Document interesting experiments and discoveries.

## Focus Areas

1. Numerical computing and statistics
2. Probability and statistical estimation
3. Regression and optimization
4. Decision trees and gradient boosting
5. Time-series forecasting
6. Advanced statistical models

## Getting Started

Install the Odin compiler and ensure it is available on your PATH.

Run the initial example:

```bash
odin run examples/hello
```

Run the starter tests:

```bash
odin test tests
```

## Philosophy

This is an educational and exploratory project, not a production ML framework.

**Build to understand. Experiment to learn. Optimize when it matters. Document what is interesting.**
